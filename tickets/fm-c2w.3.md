## What to build
The macro DSL every stateful feature in the board is declared with (spec Decision 6), as a library with its own tests. Concepts match form-engine's Zig kit (rows, groups, any, stay, explicit ignore/invalid, compile-time coverage); syntax is Elixir declarations. No :gen_statem in the MVP. Includes the project scaffold it needs to compile and test if ticket 4 has not landed yet (coordinate: whichever lands first owns the mix project).

## Interfaces
Produces: `use Board.Fsm` and the generated step/3, __fsm__/1, to_mermaid/0, matrix/0. Consumed by the stage and epic machines (ticket 5) and the merge-action machine (ticket 9).
