Description · from beads
The first playable slice of Record mode: one track, one voice, recorded against a click and looping, in the calm window. Input from keys, live MIDI, or a file played in for scripted tests. Introduces the looper and doodler-mode machines (on the kit) and the input map as data, so the Launchkey layout later is a table edit.
Acceptance · from beads
  • Pick a voice type, press record: one-bar count-in with click, record while hearing yourself; press again: the take loops
  • Stop and play work; one lane with a playhead, a status line (meter, tempo, state) and the mode
  • Looper and doodler-mode machines written with the kit; input map as a data table
  • Queued actions take effect at the next beat via boundary events, not extra states
  • Tap tempo or encoder sets tempo before the first take (default 100 bpm)
  • A scripted run produces a screenshot of the lane and a loop log; verify closeout passes
