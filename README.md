# beads-board

A local board for every beads repo on this machine, organised around epics. Status: spec approved 2026-10-17, not built yet.

- `docs/spec.md`: the approved MVP spec (authoritative).
- `docs/design.md`: the design pass and its rationale.
- `docs/mockup/`: source of the design canvas (to be revised to the epic-first layout before views are built).
